📝 富文本编辑器 DOCX 导入功能测试

功能说明

富文本编辑器已经集成了 DOCX 导入功能，使用 mammoth.js 库将 DOCX 文件转换为 HTML 格式。

支持的功能：

  • 文字格式（加粗、斜体、下划线）
  • 标题（H1-H6）
  • 段落和换行
  • 列表（有序和无序）
  • 表格
  • 图片
  • 引用
测试步骤
  1. 访问 富文本编辑器
  2. 点击侧边栏的"📁 选择文件"按钮
  3. 选择一个 .docx 文件
  4. 观察文档内容是否正确显示在编辑器中
预期效果

DOCX 文件中的内容应该能够：

  • ✅ 正确转换为 HTML 格式
  • ✅ 保持原有的格式（字体、颜色、对齐等）
  • ✅ 显示图片和表格
  • ✅ 保持段落结构
  • ✅ 支持进一步编辑
技术实现

导入流程：

1. 用户选择 DOCX 文件
2. 读取文件为 ArrayBuffer
3. 使用 mammoth.convertToHtml() 转换
4. 将转换后的 HTML 设置到编辑器
5. 更新内容状态

核心代码：

const importFromDocx = async (file) => {
  const arrayBuffer = await file.arrayBuffer()
  const result = await mammoth.convertToHtml({ arrayBuffer })
  editor.value.innerHTML = result.value
  content.value = result.value
}
注意事项
  • 确保 DOCX 文件格式正确
  • 复杂的样式可能无法完全保留
  • 导入后可以继续编辑文档
  • 导入的内容会自动保存到本地存储
